# Olist E-Commerce Data Analysis

## 📌 Project Overview
This project presents an end-to-end data analysis of the Olist E-Commerce dataset. The goal is to extract actionable business insights into sales performance, customer shopping behavior, product categories, payment trends, and delivery/logistics efficiency.

---

## 🛠️ Tech Stack & Tools Used
- **Programming Language:** Python
- **Data Manipulation & Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Database Management:** PostgreSQL, SQL
- **Environment:** Jupyter Notebook / VS Code

---

## 📊 Key Analysis & Insights Covered
1. **Sales & Revenue Analysis:** Tracking monthly trends, revenue growth, and order volumes.
2. **Customer Demographics:** Analyzing order distributions across regions and customer retention rates.
3. **Product Performance:** Identifying top-performing product categories vs. underperforming ones.
4. **Logistics & Delivery:** Evaluating delivery turnaround times, delays, and their impact on customer review scores.
5. **Payment Methods:** Understanding preferred payment types (credit card, voucher, boleto, etc.) and installment behavior.
